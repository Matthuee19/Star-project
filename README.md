The controls for my Starbie are built around two buttons and the MPU6050 motion sensor. Button 1 opens and confirms selections in the radial menu, while Button 2 switches between the pet screen and the stats screen. When the menu is open, tilting the device moves the selection cursor between the four options. The pet can also react to motion detected by the MPU6050, allowing shake interactions and menu navigation through physical movement rather than traditional directional buttons.

To personalize the project and make it my own, I customized the hardware pin assignments to match my wiring configuration, disabled the DHT11 sensor since it was not being used, and modified the radial menu by replacing the original PET option with a new DANCE action that boosts happiness while reducing energy. I also added a custom sparkle effect that appears behind the pet while it is moving, giving the character more personality and making the animations feel more dynamic. Finally, I replaced the original pet graphic with a custom sprite, changing the appearance of the character while keeping the overall virtual pet functionality intact. These changes make the project visually unique and better suited to my hardware setup while preserving the original gameplay features.
